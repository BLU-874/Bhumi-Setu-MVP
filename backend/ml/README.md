# Supervised candidate match ranking

Synthetic training benchmark — not a production accuracy estimate.

The dataset is generated by `python -m ml.build_dataset`; models are trained by
`python -m ml.train`; frozen test evaluation is `python -m ml.evaluate`.
Run these from backend using its virtual environment. Training reads only the
training and validation partitions for fitting/scoring; test evaluation is a
separate command. The dataset SHA-256 binds evaluation to the training manifest.

The two classifiers use exactly the same ordered 16 input features. Identifiers,
scenario metadata, split membership and labels are never part of the vector.
The HistGradientBoosting model handles missing values natively; the logistic
baseline uses training-fitted median imputation, missing indicators and scaling.
The installed sklearn behavior is documented in the
[official classifier reference](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html).

| Feature | Definition |
|---|---|
| intersection_over_union | Repaired polygon intersection area / union area, 0–1 |
| centroid_distance_m | Euclidean distance between polygon centroids |
| boundary_distance_m | Minimum distance between polygon boundaries; crossing boundaries give zero |
| parcel_area_sqm / building_area_sqm | Repaired geometric area in EPSG:32643 |
| area_difference_pct | Absolute geometric area difference / maximum area × 100 |
| survey_number_similarity | RapidFuzz ratio of existing normalized survey keys / 100 |
| owner_similarity | Case-insensitive RapidFuzz ratio / 100; placeholders excluded |
| attribute_similarity | Existing attribute comparator on available canonical values; 0–1 |
| survey_exact_normalized_match | Equality of existing punctuation-stripped, lowercase keys |
| gnss_inside_parcel | 1 when a contained observation exists; null when unavailable |
| gnss_related_survey_match | Contained observation survey equals parcel survey; null if either is absent |
| parcel_geometry_valid / building_geometry_valid | Original geometry validity, 0/1 |
| parcel_geometry_repaired / building_geometry_repaired | Source preparation repair marker, 0/1 |

Absent evidence is serialized as JSON null, then mapped to NaN at the estimator
boundary. A missing observation is not a failed survey. The GNSS comparison is
parcel-level evidence and will not differentiate candidates for the same parcel.
Only prepared EPSG:32643 geometry is accepted. Original IDs are used exclusively
to construct known synthetic labels and geographic metadata.

The data builder samples up to four nearest incorrect buildings, two survey-
similar incorrect buildings, all intersecting incorrect buildings if present,
and the known corresponding building if it exists. Candidates are deduplicated.
Both pair members remain in the same geographic partition. No random row split
is used. Wards 1–3 train, ward 4 validates, ward 5 tests.

The first HGB configuration and 0.5 evaluation threshold were declared before
test evaluation. No tuning or refitting on validation/test was performed.
Serialized artifacts must be locally trusted: joblib loading can execute code.
The application never accepts model uploads. A sklearn version/feature contract
mismatch disables ML and leaves deterministic results valid.

The model is invoked on the existing intersecting candidates only. It returns a
separate ranking, not a change to the deterministic selected building. Saved run
features retain all candidate feature values, scores and model version. Old runs
do not retroactively receive ML scores. Restart after replacing an artifact.
